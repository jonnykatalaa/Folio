# FolioCap - Multi Asset Portfolio Tracker

CoinMarketCap-inspired portfolio tracker UI for multiple asset classes:

- Stocks
- Crypto
- Cash
- Commodities

## Run locally

No build tooling is required. Open `index.html` directly in your browser, or serve the repository with any static server.

Example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
